# Archived per-stage notes

These are the original run notes written for each stage while the simulation was being developed. They are kept as a
record only. They refer to the folder layout used at the time (one folder per stage), contain local paths, and some
quote earlier numbers computed with a 27 dBm jammer and without the perfect-match correction.

For current instructions see [HOW_TO_RUN.md](../../HOW_TO_RUN.md). For current results see `results/stage<X>/`.
